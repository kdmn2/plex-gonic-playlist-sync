Playlist backups

The backup directory must be inside the container and persistently mounted. A host path is not usable unless mounted. Example Compose mount: ./appdata/plex-gonic-sync/backups:/backups, then set the directory to /backups. No Docker socket or privileged mode is required, and no music-directory mount is needed to export API-provided paths.
